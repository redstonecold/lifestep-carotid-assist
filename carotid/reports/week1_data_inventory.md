# 1주차 데이터 점검 결과 (2026-10-06)

원본 위치: `2026_LifeStep_홍석찬/Data/` (원본은 수정하지 않음)

## 형식별 요약

| 종류 | 파일 | 실제 내용 | 판단 |
|---|---|---|---|
| AVI | 7개 (`existing data/`) | 640×448, MS-MPEG4v2, 28.8fps, 각 73~78초(약 2,100~2,250프레임). 화면 하단에 **ECG 파형** 있음. 화면에 이름·기관 정보 없음 | 주 학습·측정 데이터. 박동 분할에 ECG 사용 가능 |
| DICOM | 6개 (P001·P002 폴더) | WMV와 같은 영상의 다른 저장 형식 | 사용자 결정에 따라 제외 |
| WMV | 5개 | P001 폴더 2개, P002 폴더 3개 | P001·P002의 주 분석 영상으로 사용 |
| TIFF | 500장 (`images/tech_*.tiff`) | 인터넷에서 수집한 불특정 다수의 정지영상. 정확한 사람 수와 이미지별 대상자 구분을 알 수 없고 라벨 없음 | 학습 전용 보조 데이터(25~50장). 검증·시험 제외 |

## 중복 및 빈 폴더

- P002의 DICOM 2개(V14 원본 DICOM과 그 사본)는 **바이트 단위로 동일** → 1개만 사용
- P009~P011의 원본 폴더 3개는 **비어 있음** (하위 WMV/DICOM 폴더만 있음). 각각 새로운 사람 1명분이며 Google Drive 업로드 누락으로 2026-10-27 기준 재전달 요청됨
- 사용 동영상 = AVI 7개 + WMV 5개 = **12개**

## mm 보정

- DICOM 보정값은 확인했지만 DICOM 형식을 사용하지 않으므로 학습·측정 파이프라인에는 적용하지 않음
- AVI: 보정 태그 없음. 왼쪽 깊이 눈금이 **64px 간격**. 눈금이 5mm라면 0.078 mm/px이고, 이때 내강 지름이 약 7mm로 계산되어 정상 총경동맥 범위와 맞음. **눈금 간격(5mm 여부)은 확인 필요** → 확인 전까지 `수동 보정(미확정)`

## 개인정보

- DICOM/WMV 화면 상단에 **기관명, 대상자 이니셜, 번호, 촬영 일시가 화면에 직접 새겨져 있음** → 프레임 추출 시 초음파 영역만 잘라 제거함
- TIFF 일부(예: `tech_001`)에도 상단 텍스트(날짜 등)가 있음 → 학습 전 초음파 영역만 잘라 제거 필요

## 확인이 필요한 사항

1. AVI 깊이 눈금 한 칸이 5mm인지
2. WMV 5개에서 경동맥과 경정맥이 함께 보이는 경우 목표 경동맥을 일관되게 구분할 수 있는지 확인
3. 비어 있는 3개 폴더의 재전달 완료 여부와 실제 파일 구성
4. TIFF 500장의 원출처·이용 가능 범위·중복 여부와 개인별 묶음 확인 가능성

## 2026-10-27 사용자 확인에 따른 정정

- `existing data`의 AVI 7개 전체 = 한 사람(P003)
- P001 원본 폴더 = 별도의 한 사람(P001)
- P002 원본 폴더 = 또 다른 한 사람(P002)
- 현재 로컬 동영상 데이터는 3명분
- 비어 있는 숫자 폴더에 대응하는 새로운 사람 3명분은 Google Drive 업로드 누락 상태이며 이번 주 재전달 예정
- TIFF 500장은 인터넷에서 가져온 불특정 다수의 정지영상이며 정확한 사람 수는 알 수 없다. 이전의 `TIFF 2명` 가정은 폐기한다
