## 1. 데이터 분할: 학습 9 · 검증 1 · 시험 1

### 용어

| 용어 | 정의 |
|---|---|
| 학습셋(train) | 모델 가중치를 갱신하는 데 쓰는 데이터 |
| 검증셋(validation) | 학습 중 epoch마다 성능을 측정해 **최적 epoch(조기 종료)와 하이퍼파라미터를 고르는 데** 쓰는 데이터. 선택에 쓰였으므로 이 점수는 실제 성능보다 낙관적으로 나온다(선택 편향) |
| 시험셋(test) | 모든 선택이 끝난 뒤 **한 번만** 평가하는 데이터. 처음 보는 대상자에 대한 일반화 성능의 비편향 추정치 |
| 사람 단위 분할 | 한 사람의 모든 프레임을 한 묶음에만 넣는 방식. 같은 영상의 인접 프레임은 거의 같아서, 프레임 단위로 나누면 학습 데이터가 평가에 새어 들어가 성능이 부풀려진다(**데이터 누수**) |

### 결정

| 역할 | 대상자 |
|---|---|
| 학습 (9명) | P001 · P002 · P003 · P005 · P007 · P008 · P009 · P010 · P011 |
| 검증 (1명) | P006 |

### 근거

- **P004·P006을 평가용으로 남긴 이유 [데이터]**: 둘 다 15초 DICOM이라 박동이 10회 이상 들어 있다. 박동별 내경 변화량(약 0.5mm) 평가는 긴 영상에서만 가능하다. 3초 클립(P001·P002·P009~P011)에는 박동이 2~4회뿐이다.
- **선택 방식 [방법론]**: P004·P006은 2026-11-03에 고정 시드(20261103)로 추첨한 결과를 그대로 유지했다. 품질을 보고 고르지 않았으므로 쉬운 사례를 고르는 편향이 없다.
- **P001(검증→학습)·P009(시험→학습) 이동**: 이미 그린 라벨 56장을 학습에 그대로 쓴다. P009 라벨은 모델 초안 없이 직접 그린 것이므로 학습에 써도 문제가 없다.
- **P003은 항상 학습 [데이터]**: 유일한 AVI 장비·ECG 영상이다. 평가셋으로 빼면 학습에서 그 장비가 사라진다.

### 한계와 보완

- 검증이 1명이므로 하이퍼파라미터가 그 1명에게 과적합될 위험이 있다. 설정 탐색 횟수를 약 20회로 제한하고, 최종 설정은 **교차검증**으로 다시 확인한다.
- **교차검증(9:1 순환, leave-one-subject-out) [문헌·표준]**: 시험 P004를 뺀 10명 중 P003을 학습에 고정하고, 나머지 9명이 한 번씩 검증자가 되어 9회 학습한다. 매회 학습 9 : 검증 1로 본 실험과 비율이 같다. Dice·HD95·내경 MAE·F 오검출률의 **평균 ± 표준편차**와 사람별 값을 보고한다.
- 검증·시험이 모두 긴 DICOM이다. 3초 클립에 대한 일반화 성능은 교차검증에서 해당 대상자가 검증자인 회차로 확인한다.

## 3. 데이터 세트 A/B/C/F

### 정의

| 세트 | 기준 | 마스크 | 학습 | 내경 평가 |
|---|---|---|---|---|
| A | 상·하벽 **내막 경계(내벽 흰 띠)**까지 선명, 혈관이 화면 좌우 끝까지 이어짐 | 내강 전체 | O | O |
| B | 내강은 식별되나 내막 경계가 보이지 않거나 흐림 | 보이는 내강 | O (가중치 0.7) | 별도 집계(참고) |
| C | 상·하벽은 보이나 혈관이 **화면 중간에서 끝나거나 끊김**(측정 가능 길이가 짧음) | 보이는 내강만 | O | 중앙 안정 구간만 |
| F | 상·하벽 중 **한쪽이 보이지 않거나** 경동맥이 **전혀 보이지 않음**(횡단면·탐촉자 이동·검출 불가) | 확실한 내강만, 없으면 **빈 마스크** | **O (필수)** | X |
| X | 동맥·정맥 구분 불확실 | - | X | X |

- 한 프레임이 여러 조건에 해당하면 더 나쁜 세트로 분류한다(F > C > B > A).

### 근거

- **A/B 구분 [데이터·방법론]**: 내경은 상·하 내막 경계 사이 거리로 잰다. 내막 경계가 흐리면 라벨 자체의 위치 불확실성이 커지므로, 학습에는 쓰되 측정 평가 기준에서는 뺀다.
- **C 분리 [데이터]**: 화면 중간에서 끝나거나 끊긴 혈관은 측정 가능 구간이 짧다. 이런 프레임을 학습에서 빼면 모델이 혈관이 길게 보이는 영상에만 익숙해진다. 학습에 넣고, 측정은 보이는 구간의 중앙에서만 한다.
- **F 학습 포함 [방법론]**: 아래 4절.

### 목표 비율 (학습 415장 기준)

| 세트 | 비율 | 장수 | 근거 |
|---|---:|---:|---|
| A | 45% 이상 | 약 190 | 내경 평가의 기준 데이터. 정답 품질이 가장 높음 [판단] |
| B | 약 20% | 약 80 | 실제 영상에서의 출현 비율에 따름 [데이터] |
| C | 약 20% | 약 85 | 상동 [데이터] |
| F | 약 15% (10~20%) | 약 60 | 상한 20%: 빈 마스크 비중이 커지면 모델이 전경(내강)을 과소 예측하는 쪽으로 치우친다(클래스 불균형) [문헌 원칙 + 판단] |

### C 기준 확정 (2026-11-10)

- 처음 정의는 "혈관 좌우 끝이 화면 밖이면 C"였다. 그러나 종단면 프레임은 대부분 혈관이 화면 끝까지 이어지므로, 이 정의로는 A가 거의 남지 않는다.
- batch01 처음 10장을 실제로 분류한 결과 **화면 끝까지 이어진 선명한 혈관은 A, 화면 안에서 끝나거나 끊긴 혈관은 C**로 나뉘었다(A 4 · C 4 · X 2, 장당 평균 45초).
- 이 구분을 정식 기준으로 확정했다. 이미 그린 라벨은 수정할 필요가 없다.

### 결정

그동안 제외했던 다음 프레임을 F세트로 학습에 넣는다(약 60장).

| 출처 | 내용 | 장수 |

### 근거

- **음성 표본(negative sample)의 필요성 [방법론]**: 양성(내강이 있는) 프레임만으로 학습한 분할 모델은 모든 입력에 대해 전경이 존재한다고 가정하게 되어, 혈관이 없는 프레임에서도 무언가를 분할한다(위양성). 실제 검사 동영상에는 탐촉자 이동·횡단면 구간이 반드시 포함된다.
- **소프트웨어 요구사항과의 연결**: 최종 소프트웨어는 측정할 수 없는 구간에 `자동측정 불가 / 검토 필요`를 표시해야 한다. 이 판정은 모델이 F 프레임에서 빈 마스크를 출력하는 능력에 달려 있다.
- **평가**: F 오검출률(7절)로 정량화한다.

## 5. 학습 루프 구조: Dataset 2개 · loop 2개

### 구조

```text
train Dataset : 학습 9명, A·B·C·F, 증강 적용, 256×256 크롭, 사람별 균형 추출
valid Dataset : 검증 P006, A·B·C·F, 증강 없음, 전체 프레임(32의 배수로 패딩)

for config in 하이퍼파라미터 설정 목록:          # 야간 연속 실행(sweep)
    for epoch in 1..80:
        train loop : model.train(), 순전파 → 손실 → 역전파 → 가중치 갱신
        valid loop : model.eval(), no_grad, 검증 지표 전부 계산
        epoch 결과 CSV 기록, valid Dice 최고 시 체크포인트 저장
        valid Dice 15 epoch 정체 시 조기 종료
```

### 용어와 근거

| 항목 | 값 | 설명·근거 |
|---|---|---|
| epoch | 9명 × 50장 = 450장 (배치 8, 57 step) | 1 epoch = 학습 데이터를 정해진 양만큼 한 번 순회하는 단위 |
| 최대 epoch | 80 | 실제 학습 길이는 조기 종료가 결정한다 [판단] |
| 조기 종료(patience) | 15 epoch | 검증 성능이 더 오르지 않으면 중단해 과적합을 막는다 [관례] |
| valid 입력 | 전체 프레임 | 실제 추론(측정)과 같은 조건에서 평가한다. 크롭으로 평가하면 측정 조건과 달라진다 [방법론] |
| 중단·재개 | 설정별 결과 CSV, epoch별 체크포인트 | 야간 실행 중 끊겨도 이어서 진행한다 |
| 실행 | `caffeinate -i python -m src.train --sweep` | macOS 잠자기 방지 |

## 6. 손실 함수

### 용어

- **손실 함수(loss)**: 예측 마스크와 정답 마스크의 차이를 수치화한 목적 함수. 역전파로 이 값을 최소화하도록 가중치를 갱신한다.
- **Dice 손실**: `1 − 2|P∩G| / (|P| + |G|)`. 영역 겹침 기반이라 전경(내강)이 화면의 일부일 때 생기는 클래스 불균형에 강하다.
- **BCE(Binary Cross-Entropy)**: 픽셀마다 계산하는 이진 분류 손실. 픽셀 단위 기울기가 안정적이다.
- **Focal 손실**: `(1 − p_t)^γ · BCE`. 이미 잘 맞춘 픽셀의 기여를 줄이고 어려운 픽셀(흐린 경계)에 가중치를 준다.
- 분할 손실함수 전체 종류와 각각을 채택하거나 제외한 이유는 **부록 A**에 정리했다.

### 결정과 근거

| 항목 | 결정 | 근거 |
|---|---|---|
| 기본 손실 | Dice + BCE (1:1) | nnU-Net 기본 손실(Dice + Cross-Entropy). 다양한 의료영상 분할 과제에서 표준 구성 **[문헌: Isensee 2021]** |
| 비교 후보 | Dice + Focal (γ=2) | γ=2는 원 논문의 최적값 **[문헌: Lin 2017]**. 흐린 경계 개선 효과는 가설이므로 1차 탐색에서 비교 |
| **Dice 계산 단위** | **batch Dice**: 배치 8장의 픽셀을 합쳐 한 번 계산(smooth = 1) | F세트는 정답이 빈 마스크다. 이미지별 Dice는 정답·예측이 모두 비면 0/0으로 정의되지 않고, 작은 위양성에도 손실이 1로 급변해 학습이 불안정해진다. 배치 단위로 합치면 분모가 0이 되지 않는다. nnU-Net의 batch Dice 옵션과 같은 방식 **[문헌·수식]** |
| F세트 학습 신호 | BCE(또는 Focal)가 빈 마스크 픽셀 전체를 배경으로 학습. batch Dice에서도 위양성 픽셀이 분모에 더해져 벌점이 된다 | 위양성 억제 [수식] |
| 세트별 가중치 | 픽셀 손실에 A 1.0 · B 0.7 · C 1.0 · F 1.0 | B는 경계 라벨의 불확실성이 크므로 기여를 낮춘다. 0.7은 **[판단]**이며, 1차 탐색에서 B 1.0과 비교해 검증 |
| 손실 기록 | 매 epoch train loss와 valid loss를 모두 기록 | train loss 감소 + valid loss 증가 = 과적합 신호 |
| 모델 선택 기준 | 손실이 아니라 **valid Dice(A·B·C)** | 손실의 절대값은 손실 종류·가중치에 따라 척도가 달라 설정 간 비교가 불가능하다 |
| 발산 처리 | 손실 NaN, 또는 처음 10 epoch 안에 3 epoch 연속 증가 시 해당 설정 중단, `발산`으로 기록 | 학습률이 큰 설정(3e-3)에서 발산할 수 있다. 야간 sweep이 한 설정에서 시간을 소모하지 않게 한다 [판단] |

## 7. 데이터 증강 파라미터

### 용어

**데이터 증강(augmentation)**: 학습 시 입력 영상에 무작위 변환을 가해 학습 분포를 넓히는 정규화 기법이다. 대상자 11명, 장비 2종의 소규모 데이터에서 장비·촬영 조건 차이에 대한 과적합을 줄이는 것이 목적이다. 학습에만 적용하고 검증·시험·추론에는 적용하지 않는다.

### 기존 구현의 문제 (이번에 발견)

전처리 순서가 `증강 → 영상별 z-score 정규화`다. 선형 밝기·대비 변환 `x' = a·x + b (a > 0)`에 z-score를 적용하면 다음과 같다.

```text
(x' − mean(x')) / std(x') = (a·x + b − a·mean(x) − b) / (a·std(x)) = (x − mean(x)) / std(x)
```

즉 **선형 밝기·대비 증강은 정규화에서 완전히 상쇄된다**(포화로 잘린 픽셀만 예외). 기존 코드의 밝기·대비 ±10%는 사실상 효과가 없었다. 그래서 정규화 후에도 남는 **비선형 변환(감마)**과 **공간적으로 불균일한 변환(깊이별 밝기)**을 밝기 증강의 중심으로 바꿨다.

### 적용 순서와 크롭

- 적용 순서: 0.1mm/px 재표본화 → 기하 변환(영상·마스크 동시, 마스크는 최근접 보간) → 256×256 크롭 → 밝기 → 화질 → z-score 정규화
- 크롭: 2/3는 무작위, 1/3은 내강 중심(F 프레임은 항상 무작위). nnU-Net의 전경 과표집(foreground oversampling) 33%와 같은 방식이다 **[문헌]**. 무작위 크롭만 쓰면 내강이 없는 패치의 비중이 커진다.
- 약·중·강은 1차 탐색 2단계에서 비교하고, 그 이전 단계는 중(기본)으로 고정한다.

### 원칙

| 구분 | 원칙 | 이유 |

| **보고 지표** | 선행연구 비교와 측정 목적에 필요한 **14종**을 보고서에 싣는다 | 표준 지표(Dice·IoU)로 선행연구와 비교하고, 측정 일치도로 프로젝트 목적을 직접 평가한다. 겹침·경계 거리·측정 일치도를 함께 보고하는 구성은 의료영상 지표 권고안(Metrics Reloaded)을 따른다 **[문헌: Maier-Hein 2024]** |

- **신뢰구간**: bootstrap 2,000회. 교차검증은 사람 단위로 재표집해 같은 사람 프레임 간 상관을 반영한다.
- **표본 수 명시**: 모든 표에 사람 수와 프레임 수를 함께 적는다.
- **반복 라벨 기준선(표 6)**: 같은 프레임을 날짜를 달리해 다시 그린 결과로 같은 지표를 계산한다. "AI 오차가 사람 간 차이와 비슷한 수준"인지 보여 주는 근거가 된다.

### 설정 선택 규칙 (사전 고정)

1. 각 설정에서 valid Dice(A·B·C)가 최고인 epoch의 체크포인트를 쓴다.
2. 최고 설정 대비 Dice가 0.01 이상 낮으면 탈락
3. F 오검출률 20% 초과 시 탈락 **[판단]**
4. 남은 설정 중 **내경 MAE 최소** 선택
5. MAE 차이가 0.02mm 이내면 HD95가 작은 설정, 그다음은 단순하고 빠른 설정

### Dice만으로 고르지 않는 이유

경동맥 내강은 가로로 긴 구조라 상·하 경계가 1~2픽셀 어긋나도 Dice는 높게 유지된다. 그러나 측정 목표인 박동별 내경 변화는 약 0.5mm로, 0.0694mm/px 기준 약 7픽셀에 불과하다. 따라서 Dice는 1차 선별에만 쓰고, 최종 선택은 mm 단위 측정 오차로 한다.

## 부록 A. 분할 손실함수의 종류

### A-0. 기본 개념

- 모델은 픽셀마다 내강일 확률 `p`(0~1)를 출력한다. 정답 마스크는 픽셀마다 `g` = 1(내강) 또는 0(배경)이다.
- 손실함수는 `p`와 `g`의 차이를 스칼라 하나로 요약한다. 학습은 이 값을 줄이는 방향으로 가중치를 갱신(경사하강)하는 과정이다.
- 손실함수는 **미분 가능**해야 한다. 그래서 0/1로 자른 예측이 아니라 확률 `p`를 그대로 쓰는 "soft" 형태로 계산한다. 검증지표는 0/1로 자른 예측으로 계산하므로 같은 이름(예: Dice)이라도 값이 조금 다르다.
- 분할 손실은 크게 **분포 기반 · 영역 기반 · 경계 기반 · 복합** 네 계열로 나뉜다 **[문헌: Ma 2021]**.

### A-1. 분포 기반: 픽셀마다 독립적으로 채점

| 손실 | 수식(픽셀 평균) | 특징 | 장점 | 단점 | 본 실험 |
|---|---|---|---|---|---|
| **BCE** (Binary Cross-Entropy) | −[g·log p + (1−g)·log(1−p)] | 정답 픽셀의 확률이 낮을수록 로그로 크게 벌점 | 기울기가 안정적이고 학습 초기에 수렴이 빠름 | 배경 픽셀이 대다수면 배경만 맞혀도 손실이 낮아짐(클래스 불균형) | **채택**(Dice와 결합) |
| 가중 BCE | 양성 픽셀 항에 가중치 w | 소수 클래스(내강)의 벌점을 키움 | 불균형을 직접 보정 | w를 따로 정해야 함. 과하면 과분할 | 미채택: Dice가 불균형을 이미 보정 |
| **Focal** | −(1−p_t)^γ · log p_t | 쉬운 픽셀(p_t가 1에 가까움)의 손실을 (1−p_t)^γ로 축소. γ=2면 p_t=0.9인 픽셀은 1/100로 줄어듦 | 흐린 경계 등 어려운 픽셀에 학습 집중 | γ가 추가 하이퍼파라미터. 단독 사용 시 학습이 불안정할 수 있음 | **비교 후보**(Dice와 결합) |
| TopK | 손실이 큰 상위 k% 픽셀만 평균 | 어려운 픽셀만 학습 | 경계 학습에 집중 | k 설정 필요, 잡음 픽셀에 과민 | 미채택: Focal과 목적이 겹침 |

### A-2. 영역 기반: 예측 영역과 정답 영역의 겹침으로 채점

| 손실 | 수식 | 특징 | 장점 | 단점 | 본 실험 |
|---|---|---|---|---|---|
| **Dice 손실** | 1 − 2Σpg / (Σp + Σg) | Dice 계수를 손실로 사용 **[문헌: Milletari 2016]** | 배경 픽셀 수와 무관해 불균형에 강함. 평가지표와 같은 기준 | 정답·예측이 모두 비면 0/0. 작은 구조에서 기울기가 불안정 | **채택**(batch Dice로 0/0 문제 해결) |
| IoU(Jaccard) 손실 / Lovász | 1 − Σpg / (Σp + Σg − Σpg) | IoU를 직접 최적화 **[문헌: Berman 2018]** | IoU 지표와 일치 | Dice와 순위가 거의 같아 추가 이점이 작음 | 미채택: Dice와 중복 |
| Generalized Dice | 클래스별 Dice에 1/(영역 크기)² 가중 **[문헌: Sudre 2017]** | 다중 클래스에서 작은 클래스 보호 | 다중 클래스 불균형 | 이진 분할(내강 1개)에서는 일반 Dice와 같음 | 미채택: 클래스가 1개 |
| Tversky | 1 − TP / (TP + α·FP + β·FN) **[문헌: Salehi 2017]** | 위양성(FP)과 위음성(FN)에 다른 가중치. α=β=0.5면 Dice와 같음 | 놓침과 과분할 중 어느 쪽을 더 줄일지 조절 가능 | α·β 설정 필요 | 보류: 검증에서 정밀도·민감도가 한쪽으로 치우치면 2차 탐색 후보 |
| Focal Tversky | (Tversky 손실)^γ **[문헌: Abraham 2019]** | 어려운 영상에 집중 | 작은 병변 분할에 유리 | 하이퍼파라미터 2~3개 | 미채택: 데이터 대비 조절 변수가 많음 |

### A-3. 경계 기반: 경계 위치의 거리로 채점

| 손실 | 원리 | 장점 | 단점 | 본 실험 |
|---|---|---|---|---|
| Boundary 손실 | 정답 경계로부터의 거리 지도와 예측 확률의 곱을 적분 **[문헌: Kervadec 2019]** | 경계 위치 정밀도를 직접 학습. 내경 측정 목적과 맞음 | 단독으로는 학습이 불안정해 영역 손실과 섞고 비율을 점차 늘려야 함. 빈 마스크(F)에서 거리 지도가 정의되지 않음 | 보류: 1차 결과에서 경계 오차(ASSD)가 목표에 못 미치면 2차 후보 |
| Hausdorff 거리 손실 | HD를 거리 변환으로 근사 **[문헌: Karimi 2019]** | 큰 경계 오류를 직접 줄임 | 계산이 무겁고 학습이 불안정 | 미채택: M2 학습 시간 제약 |

### A-4. 위상 기반

| 손실 | 원리 | 본 실험 |
|---|---|---|
| clDice | 예측과 정답의 중심선(skeleton)이 서로 포함되는지로 연결성을 보장 **[문헌: Shit 2021]**. 망막 혈관처럼 가늘고 가지 친 구조에 효과적 | 미채택: 경동맥 내강은 두꺼운 단일 띠 모양이라 연결 끊김이 주요 오류가 아님 |

### A-5. 복합 손실과 채택 근거

- **복합 손실**은 서로 다른 계열을 더해 각각의 약점을 보완한다. 의료영상 분할 손실 20여 종을 비교한 연구에서 **복합 손실(특히 Dice + CE 계열)이 여러 과제에서 가장 안정적**이었다 **[문헌: Ma 2021]**. nnU-Net도 Dice + CE를 기본으로 쓴다 **[문헌: Isensee 2021]**.
- 본 실험의 구성
  - 기본: **Dice + BCE**. BCE가 안정적인 픽셀 단위 기울기를, Dice가 불균형 보정을 맡는다.
  - 비교: **Dice + Focal**. 흐린 경계 픽셀에 집중하는 효과를 실험으로 확인한다.
  - 보류: Tversky, Boundary. 1차 결과의 오류 양상(과분할·과소분할, 경계 오차)을 보고 2차 탐색에 넣을지 결정한다.

## 부록 B. 분할 검증지표의 종류

### B-0. 기본 개념: 혼동행렬

예측(0/1로 자른 마스크)과 정답을 픽셀마다 비교하면 네 경우가 나온다. 대부분의 겹침 지표는 이 네 값으로 계산한다.

| | 정답 내강 | 정답 배경 |
|---|---|---|
| **예측 내강** | TP (맞게 칠함) | FP (잘못 칠함, 위양성) |
| **예측 배경** | FN (놓침, 위음성) | TN (맞게 비움) |

### B-1. 겹침 기반 (overlap)

| 지표 | 수식 | 의미 | 한계 | 본 실험 |
|---|---|---|---|---|
| **Dice (DSC, F1)** | 2TP / (2TP + FP + FN) | 영역 겹침의 표준 지표. 분할 논문에서 가장 많이 씀 | 경계가 몇 픽셀 어긋나도 큰 구조에서는 값이 거의 안 변함. 빈 정답에서 정의되지 않음 | **채택: epoch 선택·1차 선별** |
| IoU (Jaccard) | TP / (TP + FP + FN) | Dice와 단조 관계(IoU = D / (2 − D)). 같은 결과면 IoU가 더 낮게 나옴 | Dice와 순위가 같아 정보가 중복됨 | 보고: 선행연구 비교용 |
| 정밀도 (Precision, PPV) | TP / (TP + FP) | 칠한 것 중 맞은 비율 | 덜 칠할수록 높아짐 | 보고: 과분할(정맥 포함) 진단 |
| 민감도 (Recall, Sensitivity) | TP / (TP + FN) | 칠해야 할 것 중 칠한 비율 | 많이 칠할수록 높아짐 | 보고: 과소분할 진단 |
| 특이도 (Specificity) | TN / (TN + FP) | 배경을 배경으로 둔 비율 | 배경이 압도적으로 많아 거의 항상 0.99 이상 | 제외(원자료로 재계산 가능): 변별력 없음 |
| 정확도 (Pixel Accuracy) | (TP + TN) / 전체 | 맞은 픽셀 비율 | 아무것도 안 칠해도 90% 이상 나옴 | 제외(원자료로 재계산 가능): 불균형 상황에서 오해 소지 **[문헌: Maier-Hein 2024]** |
| 면적 유사도 (Volume Similarity) | 1 − \|FN − FP\| / (2TP + FP + FN) | 칠한 넓이가 정답 넓이와 비슷한지 | 위치가 틀려도 넓이만 같으면 1 | 제외(원자료로 재계산 가능): 위치 정보 없음 |

정밀도와 민감도는 함께 봐야 한다. 하나만 높은 것은 과하게 칠하거나 덜 칠하는 쪽으로 치우쳤다는 뜻이다.

### B-2. 경계·거리 기반 (boundary / distance)

| 지표 | 정의 | 의미 | 한계 | 본 실험 |
|---|---|---|---|---|
| Hausdorff 거리 (HD) | 두 경계 사이에서 가장 먼 점까지의 거리 | 최악의 경계 오류 | 이상치 1점에 값 전체가 좌우됨 | 제외(원자료로 재계산 가능): 잡음에 과민 |
| **HD95** | 경계 간 거리의 95백분위 | 최악에 가까운 오류. 이상치 5%는 제외 | 빈 마스크에서 정의되지 않음 | **보고**: 동떨어진 오검출 덩어리 진단, 동점 처리 기준 |
| **ASSD** (평균 대칭 표면 거리) | 양방향 경계 거리의 평균 | 경계가 평균 몇 mm 어긋났는지 | 국소적인 큰 오류가 평균에 묻힘 | **보고**: 내경 오차와 직접 연관 |
| NSD (Normalized Surface Dice) | 허용 오차 τ mm 안에 들어온 경계의 비율 **[문헌: Nikolov 2021]** | "τ mm 이내면 맞음"으로 보는 임상 지향 지표. Metrics Reloaded 권고 | τ를 임상 근거로 정해야 함 | 제외(원자료로 재계산 가능): τ(예: 반복 라벨 경계 차이) 확정 후 추가 검토 |

겹침 지표는 "얼마나 겹치나", 거리 지표는 "경계가 몇 mm 떨어졌나"를 본다. 내경 측정은 경계 위치에 달려 있으므로 거리 지표가 필요하다 **[문헌: Taha 2015; Maier-Hein 2024]**.

### B-3. 측정 일치도 (clinical measurement agreement)

분할 결과에서 계산한 내경이 사람이 잰 내경과 얼마나 일치하는지 본다.

| 지표 | 수식 | 의미 | 한계 | 본 실험 |
|---|---|---|---|---|
| **MAE** (평균절대오차) | 평균 \|AI − 수동\| | 평균적으로 몇 mm 틀리나 | 방향(크게·작게)을 모름 | **채택: 최종 설정 선택** |
| 편향 (Bias, 평균 부호 오차) | 평균(AI − 수동) | 계통적으로 크게 재는지, 작게 재는지 | 양·음 오차가 상쇄되어 0에 가까워질 수 있음 | 보고 |
| RMSE | √평균(AI − 수동)² | 큰 오차에 더 큰 벌점 | 이상치에 민감 | 제외(원자료로 재계산 가능): MAE + 일치 한계로 대체 |
| **Bland-Altman 95% 일치 한계** | 편향 ± 1.96 × SD(차이) | "AI와 사람의 차이가 95% 경우 이 범위 안"이라는 일치도 표준 표기 **[문헌: Bland 1986]** | 표본이 적으면 범위가 불안정 | 보고: 최종 보고 |
| ICC (급내상관계수) | 측정값 분산 중 대상 간 차이가 차지하는 비율 **[문헌: Koo 2016]** | 신뢰도 표준 지표(0.75 이상 양호, 0.9 이상 우수) | 대상자 간 내경 범위가 좁으면 낮게 나옴 | 보고 |
| 상관계수 (Pearson r) | 두 측정의 선형 관계 | 함께 오르내리는지 | **일치도가 아님**. AI가 항상 1mm 크게 재도 r = 1 **[문헌: Bland 1986]** | 제외(원자료로 재계산 가능): 오해 소지 |

### B-4. 검출 기반 (image-level detection)

프레임 단위로 "내강이 있다·없다"를 맞혔는지 본다. F세트를 학습에 넣었기 때문에 필요하다.

| 지표 | 정의 | 본 실험 |
|---|---|---|
| **F 오검출률** (이미지 단위 위양성률) | F 프레임 중 예측 면적 ≥ 10mm²인 비율 | **채택: 설정 탈락 기준** |
| 미검출률 (이미지 단위 위음성률) | A·B·C 프레임 중 예측 면적 < 10mm²인 비율 | 보고 |
| AUC (ROC 곡선 아래 면적) | 면적 임계값을 바꿔 가며 검출 성능 전체를 요약 | 제외(원자료로 재계산 가능): F 프레임 약 60장으로는 곡선이 거칠다. 최종 보고용으로 검토 |

### B-5. 시간 안정성 (temporal)

| 지표 | 정의 | 본 실험 |
|---|---|---|
| 프레임 간 내경 변동 | 인접 프레임 간 내경 차이의 표준편차. 박동에 의한 실제 변화보다 크면 측정 잡음 | 보고: 상위 설정에만 계산 |

### B-6. 집계 방식

같은 지표라도 평균을 내는 단위에 따라 값이 달라진다.

| 방식 | 내용 | 본 실험 |
|---|---|---|
| 프레임 평균 | 프레임마다 계산한 값을 평균 | 검증(1명)에서 사용 |

| 세트별 집계 | A·B·C·F를 나눠 따로 계산 | 모든 지표에 병기 |

## 부록 C. 보고 지표 계산식 (14종)

수식은 VS Code 마크다운 미리보기와 GitHub에서 렌더링된다.

### C-0. 기호와 공통 규칙

| 기호 | 의미 |
|---|---|
| $P$, $G$ | 한 프레임의 예측 내강 픽셀 집합, 정답 내강 픽셀 집합(예측은 확률 0.5 기준으로 0/1 변환) |
| $TP=\lvert P\cap G\rvert$, $FP=\lvert P\setminus G\rvert$, $FN=\lvert G\setminus P\rvert$, $TN$ | 혼동행렬 값(픽셀 수) |
| $N$ | 프레임 전체 픽셀 수 ($TP+FP+FN+TN$) |
| $\partial P$, $\partial G$ | 예측·정답 마스크의 경계 픽셀 집합 |
| $d(x,S)=\min_{y\in S}\lVert x-y\rVert$ | 점 $x$에서 집합 $S$까지의 최단 거리 |
| $s$ | 픽셀 간격(mm/px). 원래 해상도로 되돌린 뒤 영상별 값(E-CUBE 0.0694, AVI 0.078)으로 mm 환산 |
| $a_i$, $m_i$ | 프레임 $i$의 AI 내경, 수동 내경(mm) |
| $e_i=a_i-m_i$ | 프레임 $i$의 내경 오차(mm), $n$은 프레임 수 |

공통 규칙

- **프레임 단위 계산 후 평균**한다. 픽셀을 전 프레임에 걸쳐 합산하지 않는다(큰 혈관 프레임이 결과를 지배하지 않게).
- **겹침·경계 지표는 A·B·C 세트만** 계산한다. F 세트는 정답이 비어 있어 정의되지 않으므로 검출 지표(C-4)로 평가한다.
- **A·B·C 프레임에서 예측이 비면**(미검출): Dice·IoU·민감도 = 0, 정밀도는 계산 불가로 제외한다. 경계 거리(HD95·ASSD)는 영상 대각선 길이(mm)를 벌점값으로 넣는다. 미검출 건수는 C-4에 따로 보고한다.
- **내경 측정**은 AI 마스크와 수동 마스크에 **같은 알고리즘**(중심선 → 수직 방향 상·하 경계 거리 → 중앙 안정 구간의 중앙값)을 적용한다. 따라서 내경 오차는 분할 차이만 반영한다.

### C-1. 겹침 지표

**① Dice (DSC)**

$$\mathrm{Dice}=\frac{2\,TP}{2\,TP+FP+FN}=\frac{2\lvert P\cap G\rvert}{\lvert P\rvert+\lvert G\rvert}$$

- 범위 0~1, 1이면 완전 일치. 예측과 정답의 겹침 넓이를 두 넓이의 평균으로 나눈 값이다.
- 예: 정답 1,000픽셀, 예측 900픽셀, 겹침 850픽셀 → $2\times850/(1000+900)=0.895$

**② IoU (Jaccard)**

$$\mathrm{IoU}=\frac{TP}{TP+FP+FN}=\frac{\lvert P\cap G\rvert}{\lvert P\cup G\rvert}=\frac{\mathrm{Dice}}{2-\mathrm{Dice}}$$

- 겹침을 합집합으로 나눈 값. Dice와 일대일 대응이며 항상 Dice 이하다. 위 예시에서 $850/1050=0.810$

**③ 정밀도 (Precision, PPV)**

$$\mathrm{Precision}=\frac{TP}{TP+FP}$$

- AI가 칠한 영역 중 실제 내강의 비율. 낮으면 과분할(정맥·주변 조직까지 칠함). 예시 $850/900=0.944$

**④ 민감도 (Recall, Sensitivity)**

$$\mathrm{Recall}=\frac{TP}{TP+FN}$$

- 실제 내강 중 AI가 칠한 비율. 낮으면 과소분할(얇은 내강 누락). 예시 $850/1000=0.850$
- Dice는 정밀도와 민감도의 조화평균이다: $\mathrm{Dice}=\dfrac{2\cdot\mathrm{Precision}\cdot\mathrm{Recall}}{\mathrm{Precision}+\mathrm{Recall}}$

### C-2. 경계 거리 지표

경계 픽셀 사이의 거리를 mm로 계산한다(픽셀 거리 × $s$).

**⑤ HD95**

$$\mathrm{HD95}=\max\Big\{\mathrm{P}_{95}\big[d(x,\partial G)\big]_{x\in\partial P},\ \mathrm{P}_{95}\big[d(y,\partial P)\big]_{y\in\partial G}\Big\}$$

- 경계 간 최대 거리(Hausdorff 거리) 대신 **95번째 백분위수**를 쓴다. 상위 5% 이상치를 버린 최악 오류. ($\mathrm{P}_{95}$: 95백분위수, 양방향 각각 계산 후 큰 값. MONAI 구현과 같은 정의)

**⑥ ASSD (평균 대칭 표면 거리)**

$$\mathrm{ASSD}=\frac{\sum_{x\in\partial P}d(x,\partial G)+\sum_{y\in\partial G}d(y,\partial P)}{\lvert\partial P\rvert+\lvert\partial G\rvert}$$

- 양쪽 경계의 모든 점에서 상대 경계까지 거리를 평균한 값. **경계가 평균 몇 mm 어긋났는지**를 나타낸다.
- 내경은 상·하 경계 사이 거리다. 그래서 상·하 경계가 **같은 방향**으로 어긋나면(예: 둘 다 0.2mm 위로) 내경 오차는 상쇄되어 0에 가깝고, **반대 방향**이면(위는 위로, 아래는 아래로) 두 오차가 더해진다. ASSD와 내경 MAE를 함께 봐야 하는 이유다.

### C-3. 측정 일치도 지표 (A·C 세트)

**⑦ 내경 MAE (평균절대오차)**

$$\mathrm{MAE}=\frac{1}{n}\sum_{i=1}^{n}\lvert e_i\rvert=\frac{1}{n}\sum_{i=1}^{n}\lvert a_i-m_i\rvert$$

- AI 내경이 수동 내경과 **평균 몇 mm 다른지**. 방향은 보지 않는다. 결정 지표.

**⑧ 내경 편향 (Bias)**

$$\mathrm{Bias}=\bar e=\frac{1}{n}\sum_{i=1}^{n}e_i$$

- 부호를 살린 평균 오차. 양수면 AI가 **계통적으로 크게**, 음수면 작게 잰다. 경계를 한쪽으로 치우쳐 그리는 버릇을 찾는다.

**⑨ Bland-Altman 95% 일치 한계 (Limits of Agreement)**

$$\mathrm{LoA}=\bar e\pm1.96\,s_e,\qquad s_e=\sqrt{\frac{1}{n-1}\sum_{i=1}^{n}(e_i-\bar e)^2}$$

- 차이가 정규분포라 가정하면 **AI와 사람의 차이 95%가 이 범위 안**에 든다. 범위가 임상적으로 허용 가능한지(예: ±0.3mm)로 판단한다 **[문헌: Bland 1986]**.
- 그림: 가로축 $(a_i+m_i)/2$, 세로축 $e_i$, 편향선 $\bar e$와 일치 한계선 2개를 그린다. 내경 크기에 따라 오차가 커지는 경향도 함께 확인한다.

**⑩ ICC(2,1) 절대일치**

프레임 $n$개를 평가자 $k=2$(AI, 수동)가 각각 잰 표에서 이원분산분석으로 평균제곱을 구한다.

$$\mathrm{ICC}(2,1)=\frac{MS_R-MS_E}{MS_R+(k-1)MS_E+\frac{k}{n}\left(MS_C-MS_E\right)}$$

| 기호 | 의미 |
|---|---|
| $MS_R$ | 프레임(대상) 간 평균제곱: 프레임마다 실제 내경이 다른 정도 |
| $MS_C$ | 평가자 간 평균제곱: AI와 사람의 계통적 차이 |
| $MS_E$ | 잔차 평균제곱: 그 밖의 무작위 불일치 |

- 전체 변동 중 **프레임 간 실제 차이가 차지하는 비율**. 절대일치형이라 AI가 계통적으로 크게 재면($MS_C$ 증가) 값이 내려간다 **[문헌: Shrout 1979; McGraw 1996]**.
- 해석 기준: 0.5 미만 낮음, 0.5~0.75 보통, 0.75~0.9 좋음, 0.9 초과 매우 좋음 **[문헌: Koo 2016]**. 95% 신뢰구간을 함께 보고한다.

**⑪ 박동별 변화량 MAE**

박동 $b$에서 수동 변화량은 직접 라벨한 최대·최소 내경 프레임으로, AI 변화량은 같은 박동 구간의 AI 내경 시계열에서 구한다.

$$\Delta^{\mathrm{man}}_b=m_{\max,b}-m_{\min,b},\qquad \Delta^{\mathrm{AI}}_b=\max_{t\in b}a_t-\min_{t\in b}a_t$$

$$\mathrm{MAE}_\Delta=\frac{1}{B}\sum_{b=1}^{B}\big\lvert\Delta^{\mathrm{AI}}_b-\Delta^{\mathrm{man}}_b\big\rvert$$

- 박동별 내경 변화(약 0.5mm)를 AI가 얼마나 정확히 재는지. 대상은 P004(시험)·P006(검증)의 박동 3~5개, 목표 0.15mm 이하.

### C-4. 검출 지표 (프레임 단위)

예측 면적 $A_i=\lvert P_i\rvert\cdot s^2$ (mm²), 기준 면적 $A_0=10\,\mathrm{mm}^2$.

**⑫ F 오검출률**

$$\mathrm{FPR}_F=\frac{\big\lvert\{i\in F: A_i\ge A_0\}\big\rvert}{\lvert F\rvert}$$

- 혈관이 없거나 측정 불가인 F 프레임에서 **10mm² 이상을 칠한 비율**. 결정 지표(20% 초과 탈락).

**⑬ 미검출률**

$$\mathrm{FNR}=\frac{\big\lvert\{i\in A\cup B\cup C: A_i<A_0\}\big\rvert}{\lvert A\cup B\cup C\rvert}$$

- 혈관이 있는데 **거의 칠하지 않은 비율**.

### C-5. 안정성 지표와 기준선

**⑭ 프레임 간 내경 변동 (시간 지터)**

라벨 없는 연속 프레임의 AI 내경 시계열 $a_t$에서 5프레임 이동평균 $\tilde a_t$를 빼 고주파 성분만 남긴다.

$$J=\sqrt{\frac{1}{T}\sum_{t=1}^{T}\big(a_t-\tilde a_t\big)^2},\qquad \tilde a_t=\frac15\sum_{k=-2}^{2}a_{t+k}$$

- 심장박동에 의한 실제 내경 변화(약 1Hz)는 5프레임(약 0.13초) 평균으로 거의 지워지지 않는다. 남는 성분은 **프레임마다 튀는 측정 잡음**이다. 단위 mm.

**기준선: 반복 라벨**

- 같은 A·C 프레임 20장을 날짜를 달리해 다시 그린 마스크 $G'$로 ①~⑪을 같은 식으로 계산한다($P$ 자리에 $G'$).
- 이것이 **사람끼리의 불일치 수준**이다. AI 지표가 이 값에 가까우면 "사람이 다시 그린 것만큼 일치한다"고 보고할 수 있다.

### C-6. 집계와 신뢰구간

**프레임 평균** (검증·시험 1명)

$$\bar M=\frac{1}{n}\sum_{i=1}^{n}M_i$$

**사람별 평균의 평균** (교차검증 9명, 사람 $k$의 프레임 수 $n_k$)

$$\bar M=\frac{1}{K}\sum_{k=1}^{K}\Big(\frac{1}{n_k}\sum_{i\in k}M_i\Big)$$

- 프레임이 많은 사람이 평균을 지배하지 않게 한다.

**95% 신뢰구간 (percentile bootstrap)**

1. 표본을 복원추출로 다시 뽑는다. 교차검증은 **사람 단위**로 뽑고, 검증·시험은 프레임 단위로 뽑는다.
2. 뽑은 표본으로 지표를 다시 계산한다. 이것을 $R=2{,}000$회 반복한다.
3. 2,000개 값의 2.5백분위수와 97.5백분위수를 신뢰구간으로 쓴다.

$$\mathrm{CI}_{95\%}=\big[\,\mathrm{P}_{2.5}(\hat M^{*}_{1..R}),\ \mathrm{P}_{97.5}(\hat M^{*}_{1..R})\,\big]$$

- 같은 사람의 프레임끼리는 서로 비슷하다. 프레임 단위로 재표집하면 표본이 실제보다 독립적으로 취급되어 신뢰구간이 지나치게 좁아진다. 그래서 교차검증은 사람 단위로 재표집한다.
- 보고 형식: **평균 ± 표준편차, 중앙값 [사분위범위], 95% 신뢰구간, n(사람 수 / 프레임 수)**

### C-7. 제외한 지표 (원자료로 재계산 가능)

보고서 본문에서는 뺐지만, 저장한 프레임별 원자료로 언제든 다시 계산할 수 있다.

| 지표 | 계산식 | 제외 이유 | 대신 볼 지표 |
|---|---|---|---|
| 특이도 | $TN/(TN+FP)$ | 배경이 대부분이라 어떤 모델이든 0.99 이상. 변별력 없음 | 정밀도 |
| 픽셀 정확도 | $(TP+TN)/N$ | 아무것도 안 칠해도 약 0.9. 오해 소지 | Dice |
| 면적 유사도 | $1-\lvert FN-FP\rvert/(2TP+FP+FN)$ | 위치를 보지 않음. 정밀도·민감도와 정보 중복 | 정밀도 + 민감도 |
| HD (최대) | 양방향 최대 경계 거리 | 경계 점 하나에 값 전체가 좌우됨 | HD95 |
| NSD | τ mm 이내 경계 점 비율 | τ를 임의로 정해야 함. ASSD와 정보 중복 | ASSD |
| RMSE | $\sqrt{\tfrac1n\sum e_i^2}$ | MAE와 Bland-Altman으로 같은 정보 | MAE + 일치 한계 |
| Pearson r | 선형 상관계수 | 일치도가 아님(항상 1mm 크게 재도 1) | ICC + 산점도 |
| AUC | 예측 면적 기준 ROC 곡선 아래 면적 | 검증 F 프레임이 약 6장이라 불안정. F 오검출률과 중복 | F 오검출률 |
| valid loss | 6절 손실함수 | 성능 지표가 아니라 학습 상태 감시용 | 학습 곡선 그림 |
